# Code of conduct

ChronoGraph contributors are expected to keep collaboration respectful, specific, and safe.

- Discuss ideas and behavior without personal attacks.
- Welcome questions and different experience levels.
- Give actionable technical feedback and accept correction in good faith.
- Do not harass, threaten, discriminate, expose private information, or use sexualized language.
- Protect source data, credentials, vulnerability details, and other sensitive material.

Maintainers may edit or remove contributions and restrict participation when conduct harms the project or its community. Serious or private concerns should be raised through the repository owner's private GitHub contact channel rather than a public issue.
